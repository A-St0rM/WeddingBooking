# 11: Noter — history per Booking

**What to build:** After a phone call, the event manager writes down what was said. Months later, when the couple ring back, it is still there — and a colleague who has never spoken to them can read it.

This is the third of the manor house's stated problems: everything anyone knows about a Booking is currently in one person's inbox or their head. It is also the raw material the AI summary will read later.

**Blocked by:** 03

**Status:** ready-for-agent

**Repos:** frontend, backend

- [ ] A Note can be written on a Booking
- [ ] Each Note records who wrote it and when
- [ ] Notes are shown newest first
- [ ] A Note records whether it came from a phone call, an email or is an internal remark
- [ ] Notes are visible to every role that can see the Booking
- [ ] Notes are never deleted
